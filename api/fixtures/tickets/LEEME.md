# Tickets de prueba de Mis gastos

Lo que devolveria el paso de lectura (Gemini) para cuatro tickets vistos en fotos
publicas de prensa (2026-11-22). Solo el texto de las lineas: no se guardan las
fotos. El DNI, la tarjeta y el nombre son INVENTADOS, para probar que la API los
descarta aunque el modelo los transcriba.

- carrefour.json: ticket digital publicado por Clarin (02/2025), con codigo de barras por linea.
- coto.json: lineas de fotos de un ticket de Coto (tipotexto.com), codigo interno + codigo con un 0 adelante, promos en linea propia. En dos fotos que se superponen.
- jumbo.json: ticket publicado por La Nacion (01/2025), codigo de barras por linea.
- dia.json: ticket publicado por La Nacion (01/2025), solo texto abreviado.
